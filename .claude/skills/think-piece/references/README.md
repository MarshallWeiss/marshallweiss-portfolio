# Atlantic-Style Article References

This folder contains example articles used to train the think-piece writing skill.

## How to Add Articles

1. Open this folder in your code editor
2. Create a new `.md` file for each article (e.g., `article-1.md`, `creativity-paradox.md`, etc.)
3. Copy the full article text from The Atlantic, NYT, or similar publications
4. Paste into the file and save
5. Add metadata at the top if helpful:

```markdown
---
source: The Atlantic
author: Author Name
title: "Article Title"
url: https://...
date: YYYY-MM-DD
---

[Article content here...]
```

## What to Include

Good examples of Atlantic-style think pieces with:
- Philosophical/cultural analysis
- Strong narrative voice
- Big ideas explored through specific examples
- Questions about meaning, purpose, identity, culture
- Essays that make you think differently

Aim for 3-5 articles to establish patterns.
